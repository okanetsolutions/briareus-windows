The catalog tests check read/manage/admin and removal of each operation, including
adjacent operations remaining available; the app store checks actual named calls.
Shared preexisting store tests cover cancelled/replaced requests. Feature-specific
screen/account lifetime coverage remains in each feature PR; the session transport
failure matrix is not evidence that every mail/MCP/Slack state transition passed.

The client consumes server dollar fields. It does not reproduce Claude baselines,
Codex cache-share pricing, or absorbed-estimate reconciliation. Session decoding
preserves `usage`, while the conversation subtitle currently reads the session's
own `costUsd`; the usage panel and pull-run totals read `usage.costUsd`. Existing displays do not consistently label `costEstimated` or
`estimatedCostUsd` provenance. These parsing tests do not certify every cost
display, estimate labeling or its native rendering.

# Server Resources

The Server button in global ◉ Status opens a read-only dashboard when the token and route catalog support `server_stats`. `/stats/server` and `/stats/sessions` need `read`; the latter independently gates the open-session section. Each row opens Session Resources only when `session_stats` is supported.

Machine CPU is percent of all cores; process and session tile/row CPU is percent of one core. Gauges show a share of the machine, and both CPU history lines use percent of all cores. Only gauges clamp at 100%; raw values remain truthful. Byte labels use powers of 1024, matching Swift. Missing, negative, nonfinite and malformed numeric fields stay unavailable; a measured zero remains zero. Inconsistent total/free memory cannot produce fabricated usage. History rejects invalid times, sorts and deduplicates samples, retains the latest sample's hour and leaves missing values and sampling gaps unconnected. Empty history remains a starting state; sample age exposes a stopped sampler.

Server figures and open sessions have separate loading/error/freshness, request slots, Pollers and retry deadlines. Each polls at the supplied interval, at least two seconds, only while visible and active. Hidden, minimized, detached and destroyed screens cancel pending requests. A route failure does not erase the other route's usable data or cooldown. Same-route Retry-After is shared across concurrent views and survives refresh, hiding and reopening. A scoped 403/404 clears the affected route across surviving views and advances its refusal generation; older successes cannot restore it, including after recovery. The existing request-owned finalizer handles cancelled terminal refusals after screen destruction and invalidates credentials/cache on a correctly scoped 401 across every Resources view. Replacement clients/devices are immune to obsolete results.

Open sessions sort by CPU, then memory, then ID for deterministic ties; unknown CPU sorts below measured zero. Names and navigation records come from the accessible projects' saved session lists, with the first matching ID winning. Unknown sessions open an ID/title record without an invented repository. No per-row reads, UI writes or commands are added. Poll replacement and refusal invalidate previously rendered row actions.
